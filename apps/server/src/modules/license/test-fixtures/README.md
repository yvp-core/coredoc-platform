# License test fixtures

`test-license-private.pem` / `test-license-public.pem` are a throwaway Ed25519
keypair generated for unit tests **only**. They are committed on purpose so the
round-trip test (`license-tool.mjs issue` → server verifier) needs no key
material at test time.

This is **not** the production license key:

- the production public key lives in `../license-format.mjs`
  (`LICENSE_PUBLIC_KEY_PEM`), which is still a placeholder in the repository;
- the production private key never enters this repository — it is generated by
  `node apps/server/scripts/license-tool.mjs keygen --out <path outside the
  repo>`, which refuses to write inside the repo.

A license signed with this fixture key is worthless against a released image.
