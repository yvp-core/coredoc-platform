- **Evals gates test built dist, not src** (2026-07-24): eval/parity gates import the workspace packages from built output — run without rebuilding and you silently test stale code → rebuild the packages before any eval run.
- **Prisma case-insensitive equals is an unescaped ILIKE** (2026-07-24): `{ equals, mode: 'insensitive' }` becomes ILIKE with user input as the pattern — a wildcard leak in tenant-scoped filters → escape the input or compare with raw lowercased equality.
- **A stale desktop build masks changes** (2026-07-24): "the feature doesn't work" in the desktop app is often an old server/preload/renderer build, not a defect → rebuild and restart both before debugging.
- **`psql` on PATH may be an impostor** (2026-07-24): a rogue npm package installs a `psql` that is not the postgres client → for the local dev DB, exec into the postgres docker container instead.
- **Broad auto-format sweeps untouched files** (2026-07-24): running the formatter with write mode on a whole directory pulls unrelated files into your diff → scope it to the paths you actually changed, revert drive-by churn.
- **A glob in a block comment can close it early** (2026-07-24): a `*/` sequence inside a `/* */` or JSDoc comment — e.g. a `**/urls.py`-style glob — terminates the comment early and turns the rest into broken code (esbuild: "Expected ; but found @") → keep globs out of block comments (use `*.py`, drop the leading `**/`, or a line comment).
- **Name-keyed CST indexes fabricate cross-file edges** (2026-07-24): a tree-sitter substrate keying its def/class index by bare symbol name resolves `self.method()` / imports to the FIRST same-named symbol repo-wide (Django `Meta`/`Config`/`Migration` collide, passing a name-only precision guard) → file-qualify the key (`${relPath}#${name}`) and look up with the caller's path.
- **An oracle built on truncated output cannot fail** (2026-07-25): a test that reads a *rendered* string — one an id cap, a length budget or any other display bound trims — is blind to every divergence past that bound, so a mutation that genuinely broke the code left the suite green → assert against the raw classification, or run one subject per invocation so there is nothing left to truncate.
- **Retiring a vocabulary term needs a repo-wide grep for its readers** (2026-07-25): the blast radius of dropping an enum value was derived from the tree that *defines* it, while the two consumers that *read* it lived in other packages — removing it would have silently frozen a shipped feature's completion signal → grep the whole repo for the literal, and when readers exist, deprecate (stop writing it) before removing.
- **A subagent's declared tools are not the roster's tool column** (2026-07-28): the harness's agent-type listing showed "(Tools: All tools)" beside an agent whose frontmatter declares `tools: []`, and that was reported as a capability leak — a live dispatch then answered `NO TOOLS` and could neither read a file nor run a command → establish a subagent's capability by dispatching it and asking what it holds, never by reading the roster line, which describes the type and not the grant.
- **A wall-clock budget sized against a host ceiling cannot be exhausted by a suite** (2026-07-28): a 30-second per-moment budget under a 60-second hook ceiling needs 30 real seconds to reach, so the twins for it would have added minutes of sleeping to a 30-second suite → make the deadline a parameter of the operation defaulted from the constant, drive the operation in-process with a deadline the case sets, and assert the constant's own ordering against the host ceiling as a separate case.
- **A tool's own new artifact can silently defeat its "nothing changed" refusal** (2026-07-28): writing a per-run summary file into the tree before computing what to stage made every run non-empty, so the refusal for a run that changed nothing could never fire again → compute the staged set from the tree first, then write the tool's own bookkeeping and add it to that set by name.
- **Writing a new row kind into a shared table means sweeping that table's existing readers, and no review lens scoped to the diff will find them** (2026-07-29): a change added a second producer to the rework-episode table with a column marking which producer each row came from, and six aggregating readers — a journey mart's rework count, a summary rollup, two graph-fusion reads, a detail timeline, a nightly sweep — kept reading the table whole, so stage boundaries counted as rework and a five-stage run read as "5 rework" on work nobody redid; four code-review lenses and a spec-conformance track all missed it because every one of those readers lives in a file the diff never touches → after adding a producer, grep the table's every read site and ask of each *does this consumer know what I now produce*, which is the read-side twin of grepping for a retired term's readers.
- **A fixture in the order the code sorts it into cannot prove the sort** (2026-07-29): the only thing establishing record order was a sort in the reader, every fixture was already written in that order, so deleting the sort left the whole suite green — the same blind oracle as asserting on truncated output, arriving as fixture order rather than as a display bound → write the fixture deliberately out of order, and prove the case by removing the sort and watching it go red.
- **A rollback restores what was written and cannot unsend what was emitted** (2026-07-29): a call that appends a durable record and emits its telemetry fact in one act has two halves, and a compensating restore covers only the first — so a failed attempt is already on the wire, and where that channel keys records by a content digest (which carries no order at all), a reader taking "the last" publishes an arbitrary attempt → order such records by the moment they were observed, the one axis both sources share and the only one monotone in retries.
- **A two-subject case whose subjects agree in every asserted field proves no mapping** (2026-07-29): a test that fixes two findings both expecting the same label passes even when the code writes one subject's label onto every record → make the subjects differ in every field the mapping produces, and assert the results as pairs.
- **A consumer that models one shape of a polymorphic result reads every other shape as empty** (2026-07-29): a licence over a code-graph reading was written against the shape the tool returns for a *function*, while the same tool answers a type with a different array, an entity from an unbounded query, and an unresolved target with a structurally perfect empty result — so a type the whole repository depends on rendered as "reaches nothing", a typoed symbol rendered as a trustworthy claim that the change reaches nothing, and a row cap was compared against rows no cap bounds; every one of thirty tests stayed green because every fixture was the one shape → enumerate the producer's own branches at the producer before consuming it, detect its not-found sentinel by its identity field rather than by the emptiness of its sets, and take one real payload per branch as a fixture.
- **A terminal state is only terminal at the writers that check it** (2026-07-30): a run's loud stop was refused by the advance verb and the commit gate, and by nothing else — so a stopped run could be stopped again with a different reason (the last one winning the archive), a red result could be admitted after the stop, and a reviewer could be dispatched onto the committed record of a run that already died → when a state means "nothing more happens", enumerate every writer that appends to the subject and give each one the refusal, through one shared precondition rather than one spelling per writer.
- **An invariant quantified over observed events is vacuously true when nothing was observed** (2026-07-30): "every dispatched reviewer records a result" held perfectly on a review stage that dispatched nobody, so an empty review committed cleanly and the always-on reviewer was held by orchestration prose alone → when a member is supposed to be always-on, the gate must owe its result unconditionally; a pairing check over what happened cannot demand what should have happened.
- **A subagent that dies mid-response has usually already written its files** (2026-08-05): four of ten workflow agents failed with `Connection closed mid-response`, and the run reported them as errors with no result — but the largest had finished writing a new module, its tests and three rewired call sites, all green, and treating the failure as "nothing happened" would have redone hours of work → on any agent failure, check the working tree, typecheck and run the tests before concluding anything was lost; only the structured report is reliably gone.
- **Phase barriers turn one agent's death into an unrelated agent's cancellation** (2026-08-05): two independent fixes were sequenced behind a barrier solely because both touched one orchestration file, so when the first phase's agent died the second phase never ran at all → give concurrent agents disjoint file ownership and let them run in one phase, reserving a barrier for a stage that genuinely needs every prior result.
- **A boolean gate over a per-occurrence measurement admits pairs it cannot see** (2026-07-30): the validator records one false completion per red admission while the commit gate asked only "does a failure exist and does a disposition exist" — so two admissions with one disposition committed straight past the honesty gate, while the disposition verb beside it was already counting → when the writer appends one record per occurrence, every reader that gates on it compares counts, never existence, or the two readers disagree about what disposed means.
- **Distill design extraction into repo-local specs before fanning out** (2026-08-08, figma-styles-update): raw Figma-MCP output is per-agent and dies with its context, so parallel implementers re-extract or re-guess values → one distillation pass into `.scratch/<slug>/design-specs/*.md` (exact px/hex/variable names, generalizable-vs-specific called out) becomes the single normative source; eight implementers and seven reviewers ran off those files with zero repeat extractions.
